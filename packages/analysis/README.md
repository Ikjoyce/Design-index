# Analysis pipeline

Provider adapters, model configuration, prompts, and validated analysis results. Keep model IDs configurable, record provenance and reported usage, preserve user edits during re-analysis, and enforce image/training privacy permissions. The owner's later decision delegates all allowance and billing limits to the Go account, superseding the original plan's local budget cap.

Implemented: 24 reviewed OpenCode Go vision models across Anthropic Messages, OpenAI Responses, compatible Chat Completions, and Google Generate Content. Includes structured schemas/JSON fallback, vocabulary/palette validation, captured CSS evidence with image-only motion guardrails, input-size preflight, honest client/session headers, Go + models.dev capability intersection, model-specific privacy/training consent, and sanitized Go rate-limit errors with Retry-After. Evaluation preserves raw motion predictions instead of applying the library's image-only repair. Allowances, billing, and Extra Usage are delegated to the Go account; no local monetary controls or endpoint/provider fallback. The server owns durable execution; see `docs/opencode-go.md` and `docs/capture-evaluation.md`.
